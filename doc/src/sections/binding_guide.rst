Binding author guide
====================

The `binding author guide <https://github.com/Biglup/cardano-c/blob/main/BINDINGS.md>`_
defines public API design, the native memory model, callback ownership, and
conformance requirements. Its canonical source is ``BINDINGS.md`` in the repository.

The `shared conformance corpus <https://github.com/Biglup/cardano-c/tree/main/lib/tests/vectors/bindings/v1>`_
contains machine-readable cases and instructions for binding adapters.
